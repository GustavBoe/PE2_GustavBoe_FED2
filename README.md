# Holidaze

## Project Exam 2

![Holidaze landing page](https://i.imghippo.com/files/JKy4620u.png)
**Holidaze is the app for booking the perfect venue for your weekend, vacation and happening.**

<hr/>

### Technology

- _React_
- _Vite v8.0.14_
- ESLint v10
- _TypeScript v6.0.3_
- _Tailwind v4.3_

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/GustavBoe/PE2_GustavBoe_FED2
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

### Viewing app

```bash
Go to  http://localhost:5173/ in your preferred browser to see the app
```
> #### Good to know:
>> **The project lacks an useAuth(), so the user has to manually refresh the pages for the components to change state!**
